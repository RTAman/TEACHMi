# TEACHMi

대학생이 강의자료에서 개념을 골라 AI 학생에게 설명하고, 문제 풀이와 성장 리포트로 이해도를 확인하는 서비스입니다. 2026년 11월 5일(목)부터 8일(일)까지 기획·디자인·프론트엔드·백엔드가 이 저장소에서 시연 버전을 만듭니다.

## 팀 작업 방법

1. 비공개 저장소 초대를 수락한 뒤 `git clone https://github.com/RTAman/TEACHMi.git`으로 내려받습니다.
2. [이슈 목록](https://github.com/RTAman/TEACHMi/issues)에서 내 파트의 작업을 열고 담당자를 지정합니다. 다른 파트의 결정이 필요하면 그 이슈에 화면 링크, API 예시 또는 확인할 내용을 남깁니다.
3. 코드를 바꿀 때는 최신 `main`에서 작업 브랜치를 만듭니다. 예를 들어 12번 이슈의 가입 작업은 `feat/12-signup`으로 시작합니다.
4. 변경을 올린 뒤 `main`을 대상으로 PR을 엽니다. 본문에 `Closes #12`처럼 실제 이슈 번호를 넣고, 같은 기능을 연결하는 팀원에게 리뷰를 요청합니다. 기획·디자인만 바뀐 작업은 결정과 Figma 링크를 이슈에 남기고 완료 처리합니다.
