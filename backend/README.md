# 백엔드

백엔드 세 명은 같은 서버와 데이터베이스를 사용하고, 담당 API를 기능별로 나눕니다. [공통 작업 계획서](../TEACHMi%20백엔드%20작업%20계획서.docx)는 전체 일정과 API 계약을, 아래 가이드는 각 담당자의 날짜별 작업과 완료 기준을 담고 있습니다.

| 담당 | 개발 가이드 | 먼저 공유할 결과 |
| --- | --- | --- |
| A | [인증·자료·개념](../TEACHMi%20백엔드%20A%20개발%20가이드.docx) | 현재 회원을 확인하는 공통 기능, 자료 분석 상태와 개념 ID |
| B | [학습 세션·AI 대화](../TEACHMi%20백엔드%20B%20개발%20가이드.docx) | 학습 세션 ID, 재개할 단계, 최초·최종 설명과 도움 기록 |
| C | [홈·평가·리포트·배포](../TEACHMi%20백엔드%20C%20개발%20가이드.docx) | 회원별 홈 응답, 답안 제출 예시, 리포트 조회 결과 |

개발 스택 제안은 Java, Spring Boot, Spring Data JPA, PostgreSQL입니다. 가입·로그인은 이메일과 비밀번호를 기본안으로 두고, 로그인 세션과 학습 기록을 분리합니다. 모든 학습 API는 서버가 확인한 현재 회원의 기록만 다룹니다.

API 경로는 `/api/v1`로 시작합니다. 실제 API 키, 비밀번호, 세션 쿠키는 커밋하지 않습니다. 팀에 공유할 설정 예시는 `.env.example`에 키 이름과 예시 값만 적습니다.
